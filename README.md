# 推し活手帳 — GitHub Pages 公開手順

## フォルダの中身
```
index.html      アプリ本体
manifest.json   PWA設定（アプリ名・アイコン・色）
sw.js           オフラインキャッシュ用サービスワーカー
icons/          ホーム画面アイコン（192px・512px・maskable）
```
この4点はすべて同じフォルダに置いてください（パスがすべて相対参照のため）。

## 手順

1. GitHubで新しいリポジトリを作成する（例：`oshikatsu-app`）。Public にしてください（無料プランでPagesを使う条件）。
2. このフォルダの中身（`index.html` `manifest.json` `sw.js` `icons/`）をリポジトリのルートにそのままアップロードする。
   - GitHubの「Add file → Upload files」からドラッグ＆ドロップでOK。`icons` フォルダごとドロップすれば階層も保たれます。
3. リポジトリの **Settings → Pages** を開く。
4. **Source** を「Deploy from a branch」、**Branch** を `main` / `/(root)` にして **Save**。
5. 1〜2分待つと、ページ上部に公開URLが出ます。
   `https://ユーザー名.github.io/リポジトリ名/`

## スマホへの追加

- **iPhone（Safari）**：公開URLを開く →共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：公開URLを開く → メニュー（︙）→ 「アプリをインストール」／「ホーム画面に追加」

追加後はアイコンから単独アプリのように起動します（アドレスバーなし）。一度開けばオフラインでも起動・閲覧できます。

## 更新するとき

`index.html` を直したら、`sw.js` の1行目付近にある
```js
const CACHE = 'oshikatsu-cache-v1';
```
の `v1` を `v2` のように上げてから再アップロードしてください。バージョンを変えないと、古いキャッシュが使われて更新が反映されないことがあります。

## データについて

記録はブラウザ（端末）の中だけに保存されます。サーバーには送信されません。機種変更や別ブラウザに移すときは、アプリ内の「設定 → 書き出す」でJSONを保存し、新しい端末で「読み込む」から復元してください。
